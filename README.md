微信自动回复程序使用说明
===================

1. 程序功能：
   - 监控微信@所有人消息
   - 根据配置的禁用关键词决定是否自动回复
   - 支持'扣XX接单'模式匹配

2. 使用方法：
   - 双击运行 main.exe
   - 在界面中勾选需要禁用的关键词
   - 点击"开始监控"启动程序
   - 点击"停止监控"停止程序

3. 配置说明：
   - 禁用关键词保存在 config.json 文件中
   - 可以编辑该文件添加或删除关键词
   - 程序会自动读取配置文件

4. 注意事项：
   - 确保微信窗口保持打开状态
   - 程序运行时请勿关闭微信
   - 如需修改关键词，可在程序关闭时编辑config.json文件

5. 故障排除：
   - 如果程序无法启动，请确保已安装Python环境
   - 如果找不到微信窗口，请确保微信已打开并显示在屏幕上
